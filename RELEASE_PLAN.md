# StoryForge: локальный коммерческий выпуск

Модель: единоразовая покупка локальной программы; покупатель вводит собственные
API-ключи. Продавец не предоставляет и не перепродаёт AI-квоты.

## Уже реализовано

- Локальные брифы: ручное сравнение роликов ниши по просмотрам/день, приблизительный
  разбор собственного/разрешённого видео по длительности, формату и частоте склеек.
- Исходный видеофайл временно обрабатывается и удаляется; кадры и аудио референса
  в новый проект не копируются. Бриф редактируется и передаётся в сценарий.
- Исследование не вызывает AI API. Доступ к локальному API из чужих браузерных
  источников запрещён. Собранный интерфейс обслуживается тем же локальным сервером.
- Генерация текста, сцен, локальная озвучка/карточки и экспорт MP4 проверены
  офлайн-тестами; внешний провайдер вызывается только при явном запуске генерации.
- Кнопка скачивания полной резервной копии базы и медиа без ключей. Восстановление
  в новую папку, без перезаписи текущей библиотеки. Перед первой миграцией старой
  базы автоматически сохраняется отдельный снимок SQLite.
- Локальная предполётная проверка FFmpeg, места на диске, доступа к папке и
  голоса Windows без внешних AI-запросов. Перед пакетными внешними запросами
  интерфейс показывает предупреждение о возможных расходах.
- Просмотр и скачивание YouTube-пакета работают офлайн; AI-вариант запускается
  только отдельным POST-запросом и может расходовать ключ покупателя.
- Скрипт `build-windows.ps1` создаёт переносимую папку `release/StoryForge` без
  включения пользовательских проектов и ключей. В собранной версии данные
  хранятся в `%LOCALAPPDATA%/StoryForgeAI`.

## Копия и восстановление

В «Диагностике» нажмите «Скачать копию». ZIP содержит базу и медиа внутри папок
проектов, но не API-ключи и не внешние файлы вне проектов. Чтобы проверить
восстановление без риска для текущих данных:

    StoryForge.exe --restore "C:\\path\\backup.zip" "C:\\path\\NewStoryForgeData"
    StoryForge.exe --data-dir "C:\\path\\NewStoryForgeData"

Папка назначения должна отсутствовать. Не удаляйте исходную библиотеку, пока
не проверите восстановленную. На новом компьютере ключи вводятся заново.

## До продажи как стабильного продукта

1. Проверка exe на чистых Windows 10/11 с обычной учётной записью. На текущем
   компьютере политика управления приложениями блокирует запуск самособранного
   exe, поэтому собранный файл нельзя считать проверенным релизом.
2. Подписанный установщик, безопасные обновления, лицензии зависимостей и
   FFmpeg, EULA, политика приватности и инструкция для покупателя. FFmpeg пока
   не включён в дистрибутив и должен быть установлен отдельно.
3. Надёжная работа с внешними файлами вне папок проектов; удобное восстановление
   из интерфейса после закрытия программы. Сейчас доступен безопасный CLI.
4. Жёсткий пользовательский предел расходов на уровне backend; текущие
   предупреждения в интерфейсе не заменяют такой предел.
5. Несколько реальных пользователей бета-версии: измерить ошибки, время до
   готового ролика, результат после перезапуска и объём поддержки.

## Дорогие функции следующего этапа

- Настоящий монтажный таймлайн с точной синхронизацией речи/субтитров, B-roll,
  музыкой, переходами, предпросмотром и экспортными профилями.
- Исследование ниши через официальный API по ключу покупателя с прозрачными
  квотами, источниками, выборкой и датой наблюдения; без ложного «точного спроса».
- Анализ референса по предоставленному пользователем разрешённому видео:
  структура, темп, графика и звук; генерация оригинального сценария с проверкой
  сходства. Не добавлять скачивание чужих роликов.
- Проверка фактов с источниками, шаблоны канала, пакет заголовков/обложек и
  короткие версии 9:16.

«Никаких проблем» гарантировать нельзя: сторонние модели, тарифы и лимиты
меняются. Критерий релиза — сохранность данных, контролируемые расходы,
понятные ошибки и восстановление после сбоя.
