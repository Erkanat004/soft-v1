# Проверка устойчивости StoryForge

CODE CLIMB не изменялся в рамках этой работы.

## Локальный запуск

Запустите start.bat из папки soft v1. Backend работает в одном процессе
на 127.0.0.1:8000, интерфейс — на 127.0.0.1:5173.
Занятые порты теперь не приводят к принудительному завершению чужих программ:
закройте предыдущий экземпляр самостоятельно. Обычный запуск без --reload,
чтобы изменения файлов не прерывали генерацию.

После сборки frontend можно запустить `run-local.bat`: один локальный порт 8000,
без работающего Vite/Node. Вкладка «Исследование» анализирует разрешённый
видеофайл и вручную введённые показатели ниши без AI-запросов; исходный файл
не сохраняется в проект. Подробный план коммерческого выпуска — RELEASE_PLAN.md.

В настройках Gemini укажите Model ID = auto. Код выбирает новые стабильные
Flash-модели, потому что models.list иногда содержит уже отключённые модели.
При 404 в режиме auto он пробует следующую модель; явно выбранную модель
не подменяет. Старые Imagen-настройки используют автоматический выбор
доступной графической модели.

Для сценария режим auto_text использует Gemini, а при временном отказе —
настроенный OpenRouter. Это означает отправку текста второму провайдеру;
если это нежелательно, выберите только Gemini в форме создания проекта.
OpenRouter по умолчанию использует бесплатный маршрут openrouter/free;
конкретная бесплатная модель может меняться и иметь ограничения по квоте.

Новый проект по умолчанию использует локальные карточки вместо потенциально
платной AI-генерации изображений и голос Windows вместо внешнего TTS.
В форме можно явно выбрать другие провайдеры. Локальные карточки не являются
AI-иллюстрациями. Для них сценарий разбивается на сцены без дополнительного
API-запроса, а кириллический текст рисуется шрифтом с поддержкой русского языка.
После озвучки сцены не разрезаются по приблизительному числу слов: без точных
временных меток такое деление могло рассинхронизировать звук и субтитры.
Субтитры выводятся короткими фразами, а не целым абзацем на экране.

## Что защищено

- Одновременные изменения одного проекта отклоняются с 409; чтение и отмена доступны.
  Защита рассчитана на один процесс локального сервера, не на несколько workers.
- Отмена связана с реальной задачей; FFmpeg завершается перед освобождением проекта.
- Перезапуск помечает незавершённые задания как прерванные.
- Замена сцен проходит одной транзакцией; текст проверяется на сохранность.
- Сохранённый сценарий не генерируется заново авторежимом, улучшения возвращаются черновиком.
- Gemini auto не полагается на порядок моделей в models.list. После 429 вводится
  пауза; временные ошибки повторяются ограниченное число раз.
- Mock-режим выбирается явно, а не выдаёт заглушки за успешную генерацию.
- Ошибки чтения/создания медиа не считаются успешным результатом.
- Ручная правка промпта заменяет старый улучшенный промпт. Версии изображений
  сохраняются отдельными файлами; недействительные и слишком большие загрузки
  отклоняются без замены предыдущего медиа.
- При изменении формата кадра, разрешения, визуального стиля или голоса
  зависимые материалы помечаются устаревшими. Экспорт не использует устаревшие
  изображения и озвучку.
- Готовый MP4 имеет отпечаток входных материалов и настроек. После правок
  предыдущий файл остаётся доступен, но интерфейс показывает, что он устарел.
  При ошибке или отмене FFmpeg временные файлы экспорта удаляются.
- Кнопка «Удалить все» удаляет только каталоги известных проектов;
  ошибки очистки медиа возвращаются в интерфейс. Удаление не является резервным копированием.
- Опрос статуса останавливается для исчезнувших/завершённых заданий и замедляется при потере связи.

## Повторяемая проверка

В PowerShell из backend:

    .\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
    .\.venv\Scripts\python.exe -m pytest test_offline_mode.py test_resilience.py -q -p no:cacheprovider

Из frontend:

    npm.cmd run build

Тесты создают отдельную временную SQLite-базу и медиа. Реальные платные API
не вызываются: ошибки 400/401/403/404/429/503 и некорректные ответы имитируются.
При наличии FFmpeg выполняется настоящий короткий рендер.

В живой проверке проект по теме Марии Стюарт прошёл сценарий, локальную
озвучку, карточки, сборку клипов и экспорт MP4. Отдельно проверены кодеки,
длительность и поддержка кириллицы в кадре. У опубликованного исторического
материала всё равно нужно проверять факты и авторские права на заменяющие
карточки изображения.

Оба указанных для проверки ключа подтвердили доступность коротких запросов,
но длинный запрос к Gemini получал временную ошибку 503, а выбранная бесплатная
модель OpenRouter — 429. Сценарий завершился через резервный бесплатный маршрут
OpenRouter. Квоты и доступность сторонних API меняются; абсолютная
безошибочность не гарантируется. Обычные INFO-записи сервера не являются ошибками.
